console

Character and number output

Defined in: src/kernel/console.c, src/kernel/console.h

Depends only on x86.h. Turns characters and numbers into BIOS teletype calls.

Function detail

void con_putc(char c)

A thin pass-through to x86_putc. Kept as its own call — rather than every module calling x86_putc directly — so any future console-level behavior (e.g. line-ending translation) has exactly one place to live.

c
Character to write.
Returns
Nothing.

void con_puts(const char *s)

Writes a NUL-terminated string one character at a time. Does no newline translation — every string literal printed by the shell already embeds \r\n explicitly where needed.

s
NUL-terminated string.
Returns
Nothing.

void con_print_u32(uint32_t v, uint8_t base)

Formats into a small stack buffer via u32_to_str, then con_putss it.

v
Value to print.
base
Radix (10 or 16 in practice).
Returns
Nothing.

void con_print_i32(int32_t v)

Formats via i32_to_str, then con_putss it. Used by calc's result.

There is deliberately no variadic con_printf: on this 16-bit target int is 16 bits but int32_t is 32, and a hand-rolled varargs reader has no prototype to promote a call-site literal/variable to the width the format string expects — a mismatched call would silently misread the stack. Explicit, typed print functions like this one avoid that whole class of bug.

v
Value to print.
Returns
Nothing.
