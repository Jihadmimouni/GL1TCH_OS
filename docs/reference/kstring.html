kstring

Freestanding string and number helpers

Defined in: src/kernel/kstring.c, src/kernel/kstring.h

No dependencies on any other kernel module — the leaf of the dependency graph. Deliberately not named memcpy/memset/ strlen/strcmp/etc.: Open Watcom recognizes those exact names as compiler intrinsics and can emit a call using a different (register-based) calling convention than the _cdecl one actually defined here, silently corrupting arguments. Distinct names sidestep the trap entirely.

Function detail

void mem_set(void *dst, uint8_t value, uint16_t n)

Fills n bytes starting at dst with value, one byte at a time. There's no bulk rep stosb fast path — nothing in this kernel fills anything large enough for that to matter.

dst
Destination buffer.
value
Fill byte.
n
Number of bytes to fill.
Returns
Nothing.

void mem_copy(void *dst, const void *src, uint16_t n)

Copies n bytes from src to dst. Does not handle overlapping ranges (no memmove semantics) — no caller needs that.

dst
Destination buffer.
src
Source buffer; must not overlap dst.
n
Number of bytes to copy.
Returns
Nothing.

uint16_t str_len(const char *s)

s
NUL-terminated string.
Returns
The number of bytes before the NUL.

int str_cmp(const char *a, const char *b)

Like C's strcmp. Used for command-name matching in shell.c and for path segments like "."/".." in fat.c.

a, b
NUL-terminated strings to compare.
Returns
0 if equal; otherwise the sign of the difference between the first differing bytes.

int str_ncmp(const char *a, const char *b, uint16_t n)

a, b
Strings to compare.
n
Maximum number of bytes to compare.
Returns
0 if equal within the first n bytes (or either string ends first); otherwise the sign of the first difference.

int str_icmp(const char *a, const char *b)

Case-insensitive compare via to_upper on each byte. Used by fat.c's find_child so typing cd src matches a directory entry FAT stores as SRC.

a, b
Strings to compare.
Returns
0 if equal ignoring case; otherwise the sign of the first difference.

void str_copy(char *dst, const char *src)

Like strcpy — no bound on dst's size. Every caller uses fixed buffers sized for the longest string that can actually occur (e.g. an 8.3 FAT name), so this has never needed a bounded variant.

dst
Destination buffer; caller-sized.
src
NUL-terminated source string.
Returns
Nothing.

void u32_to_str(uint32_t v, char *out, uint8_t base)

Converts v to a NUL-terminated string in the given base (10 or 16 in practice; any base up to 36 works since digits beyond 9 map to 'A'..'Z'). Builds digits least-significant-first into a small scratch buffer, then reverses them into out. v == 0 is special-cased to "0" since the digit-extraction loop otherwise produces nothing for it.

v
Value to format.
out
Destination buffer; must be at least 12 bytes for base 10 (10 digits + NUL, plus one spare).
base
Radix, 2–36.
Returns
Nothing.

void i32_to_str(int32_t v, char *out)

Writes a leading - for negative values, then delegates to u32_to_str on the magnitude. Does not special-case INT32_MIN, whose magnitude overflows a positive int32_t — not reachable from calc's inputs in practice.

v
Value to format.
out
Destination buffer; must be at least 13 bytes.
Returns
Nothing.

int str_to_i32(const char **s, int32_t *out)

Parses a run of decimal digits starting at *s, writes the value to *out, and advances *s past what it consumed. This is calc.c's number token.

s
In/out cursor; only advanced on success.
out
Out: the parsed value; only written on success.
Returns
1 if at least one digit was consumed; 0 (leaving *s/*out untouched) if **s wasn't a digit at all.
