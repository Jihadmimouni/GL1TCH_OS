Function detail

void read_line(char *buf, uint16_t max_len)

Reads and echoes characters via x86_getkey until Enter (ASCII 0x0D). Backspace (0x08) erases the last character both in buf and on screen (by writing backspace, space, backspace — which moves the cursor back, overwrites the glyph with a space, then moves back again). Printable ASCII (0x20–0x7E) is appended if there's room; once max_len - 1 characters are buffered, further typed characters are silently dropped (the line is truncated, not treated as an error). Anything else — arrow keys, function keys, etc. — is ignored outright.

buf
Destination buffer.
max_len
Size of buf in bytes, including room for the NUL terminator.
Returns
Nothing. On return, buf is always NUL-terminated, and a trailing \r\n has already been written to the console.
