calc

Arithmetic expression evaluator
Overview x86 kstring console keyboard calc fat shell entry / kmain Architecture ↗

Defined in: src/kernel/calc.c, src/kernel/calc.h

Depends only on kstring.h. A standalone recursive-descent evaluator with no knowledge of the console or the shell, which is what makes it independently testable on its own. Grammar: 

expr   := term (('+' | '-') term)*
term   := factor (('*' | '/') factor)*
factor := ('+' | '-') factor | '(' expr ')' | number

Standard operator precedence, right down to unary minus binding to a factor — so -2*3 parses as (-2)*3, not -(2*3) (same numeric answer either way here, but it's the structure you'd want if a right-associative operator like exponentiation were ever added).

Function detail

int calc_eval(const char *expr, int32_t *out, const char **err_msg)

The only public entry point; everything else in calc.c is static. Resets three file-scope parser globals (the cursor and the error flag/message) before parsing — the grammar is a straight-line recursive descent with no backtracking, so a simple error flag that short-circuits the remaining parse is enough. There is no error recovery or multiple-error reporting: the first problem found wins.

expr
NUL-terminated expression, e.g. "2 + 3 * 4". Leading/trailing/interior whitespace around tokens is allowed.
out
Out: the result, only written on success.
err_msg
Out: on failure, set to a short static string — one of "division by zero", "missing closing parenthesis", "invalid number", "expected a number or '('", or "unexpected trailing characters". May be passed as NULL if the caller doesn't need it.
Returns
1 on success with *out set; 0 on failure with *err_msg set.

Internal helpers

static int32_t parse_expr/parse_term/parse_factor(void) — one function per grammar rule above, each consuming from the shared cursor and looping (not recursing) for the repeated (op term)* parts, so a long chain like 1+2+3+4 doesn't grow the call stack at all. skip_ws() is called at every point whitespace may legally appear between tokens.
