GL1TCH OS — code reference

Every function in src/kernel/, one page per module.

Each module has its own page: a function summary table, then full detail for every public function (parameters, return value, and why it's shaped the way it is), plus a short note on any internal helpers worth knowing about. For how the modules fit together rather than what each function does, see architecture.html — this index is the function-level companion to that page.

Listed bottom of the dependency graph first:

x86 — src/kernel/x86.asm, x86.h

BIOS calls (console, keyboard, disk) and the 32-bit math runtime helpers Open Watcom's codegen calls into. The only module that touches real hardware.

kstring — src/kernel/kstring.c, kstring.h

Freestanding string/number helpers with no dependencies on anything else here. Named to avoid colliding with Watcom's memcpy/strlen compiler intrinsics.

console — src/kernel/console.c, console.h

Character and number output, built on x86's BIOS teletype call.

keyboard — src/kernel/keyboard.c, keyboard.h

Line-buffered keyboard input with backspace support, built on x86's BIOS key read.

calc — src/kernel/calc.c, calc.h

A standalone recursive-descent arithmetic expression evaluator. The calc shell command.

fat — src/kernel/fat.c, fat.h

The FAT12 filesystem driver: BPB parsing, directory iteration, path resolution, file reads and writes. Backs ls/cd/pwd/cat/mkdir/touch/write/append/rm.

shell — src/kernel/shell.c, shell.h

The interactive command loop. Depends on every other module; intentionally has almost no logic of its own.

entry / kmain — src/kernel/entry.asm, kernel.c

The boot handoff from stage2 into C, and kmain, which wires everything above together.
