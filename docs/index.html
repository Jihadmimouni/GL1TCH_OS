Adding a new report

  1. Copy docs/template.html to docs/reports/YYYY-MM-DD-short-slug.html and fill in its placeholders.
  2. Add a link to it in the list above, and to the sidebar nav in every page under docs/ (see the template's header comment).
  3. Optionally render it to PDF: ./docs/build-pdf.sh docs/reports/YYYY-MM-DD-short-slug.html

Building a PDF

docs/build-pdf.sh renders any report (or this index) to a PDF next to the source file. It uses a locally installed browser/PDF tool if one is found, and otherwise falls back to running headless Chrome via Docker, so it works even on a machine with nothing but Docker installed: 

# render one report
./docs/build-pdf.sh docs/reports/2026-10-06-docker-fix-and-c-kernel-shell.html

# render every report
./docs/build-pdf.sh --all
